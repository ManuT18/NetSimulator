# NetSimulator 🌐

Un simulador de redes informáticas interactivo diseñado para estudiantes y profesionales. Visualiza el "viaje del paquete" a través de diferentes capas del modelo OSI, configura dispositivos y experimenta con topologías de red en tiempo real.

## 🚀 Características

- **Diseño Interactivo**: Arrastra y suelta equipos para crear tu topología.
- **Equipos Disponibles**: PCs y Routers con configuraciones automáticas de IP y MAC.
- **Simulación de Paquetes**: Visualiza el recorrido de los datos salto a salto.
- **Inspección de PDUs**: Analiza la encapsulación de datos (L2 y L3).
- **Visualizador Modelo OSI**: Guía educativa sobre las capas del modelo OSI.
- **Interfaz Moderna**: Estética limpia y profesional con modo oscuro soportado.

## 🛠️ Tecnologías

- **React 19**
- **Tailwind CSS v4**
- **Lucide React** (Iconografía)
- **Vite** (Build tool)

## 📦 Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/ManuT18/NetSimulator.git
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
